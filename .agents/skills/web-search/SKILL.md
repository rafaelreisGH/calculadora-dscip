# Instruções de Uso
- Priorize resultados de sites oficiais (`php.net`, `getbootstrap.com`, `getcomposer.org`).
- Quando buscar soluções para erros (StackOverflow, fóruns), adapte a resposta encontrada para o contexto do projeto (sempre priorizando a segurança e a arquitetura DAO/API) antes de sugerir a solução ao usuário.
