# Como usar a skill de banco de dados
Busca o estado atual, tabelas, colunas e tipos de dados do banco de dados do projeto. Use esta ferramenta SEMPRE que precisar escrever uma query SQL, criar um modelo, usar um ORM ou quando o usuário pedir para alterar algo relacionado ao banco de dados, para garantir que você não invente nomes de colunas que não existem.
